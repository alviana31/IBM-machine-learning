# Exploratory Data Analysis for Machine Learning

## Course Overview

This course introduces the fundamental concepts and techniques of
Exploratory Data Analysis (EDA) for Machine Learning. It covers
the process of understanding datasets, retrieving and cleaning data,
performing exploratory analysis, engineering features, and applying
statistical methods to support data-driven decisions.

## Learning Objectives

After completing this course, learners are expected to understand:

- The fundamentals of Artificial Intelligence and Machine Learning.
- Different sources and formats of data.
- Data retrieval and data cleaning techniques.
- Exploratory Data Analysis (EDA).
- Feature engineering and data transformation.
- Inferential statistics and hypothesis testing.
