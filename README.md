# Course 1 - Exploratory Data Analysis for Machine Learning

## Overview

This course introduces the fundamental concepts and techniques of Exploratory Data Analysis (EDA) and data preparation for Machine Learning.

It covers AI fundamentals, data retrieval, data cleaning, exploratory analysis, feature engineering, and inferential statistics.

## Course Modules

| Module | Topics |
|---|---|
| Module 1 | Modern AI and its Applications |
| Module 2 | Retrieving Data and Cleaning Data |
| Module 3 | Exploratory Data Analysis and Feature Engineering |
| Module 4 | Inferential Statistics and Hypothesis Testing |

## Learning Objectives

After completing this course, learners are expected to:

- Understand the fundamentals of Artificial Intelligence and Machine Learning.
- Retrieve data from different sources.
- Identify and handle common data quality issues.
- Perform Exploratory Data Analysis.
- Apply feature engineering and data transformation techniques.
- Understand statistical inference and hypothesis testing.
