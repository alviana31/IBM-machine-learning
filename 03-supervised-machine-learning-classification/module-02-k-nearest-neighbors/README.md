# Module 2 – K-Nearest Neighbors (KNN)

## Overview

This module discusses the K-Nearest Neighbors (KNN) algorithm for classification. KNN is a supervised machine learning algorithm that classifies new data based on the labels of its nearest neighboring data points.

The module covers the KNN classification process, decision boundaries, distance measurements, advantages and disadvantages, and the importance of feature scaling.

## Topics Covered

1. Introduction to KNN for Classification
2. Distance Measurement and Decision Boundaries
3. Advantages and Disadvantages of KNN
4. Feature Scaling
5. KNN Model Implementation

## Learning Objectives

After completing this module, I expect to be able to:

- Explain how the KNN algorithm works.
- Understand the role of the number of neighbors (K).
- Describe how distance measurements are used in classification.
- Understand decision boundaries in KNN.
- Identify the advantages and disadvantages of KNN.
- Explain why feature scaling is important.
- Implement a KNN classifier using Python and Scikit-learn.
