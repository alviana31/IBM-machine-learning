# Module 5 – Ensemble Methods and Bagging

## Overview

This module introduces ensemble-based methods, which combine multiple machine learning models to improve prediction performance.

The module focuses on Bagging, Random Forest, Boosting, AdaBoost, Gradient Boosting, and Stacking.

These methods combine predictions from multiple models using different strategies. Some methods build models independently, while others train models sequentially to improve previous predictions.

## Learning Objectives

After completing this module, I should be able to:

- Explain the concept of ensemble learning.
- Understand how multiple models can be combined.
- Describe Bootstrap Aggregating (Bagging).
- Explain how Random Forest introduces additional randomness.
- Understand the basic concept of Boosting.
- Differentiate AdaBoost and Gradient Boosting.
- Explain how Stacking combines different models.
- Implement ensemble classifiers using Scikit-learn.

## Topics Covered

1. Introduction to Ensemble-Based Methods
2. Bootstrap Aggregating (Bagging)
3. Random Forest
4. Boosting
5. AdaBoost and Gradient Boosting
6. Stacking
