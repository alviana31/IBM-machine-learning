# Module 5 – Ensemble Methods and Model Interpretability

## Overview

This module explores ensemble methods and model interpretability in machine learning. Ensemble methods combine multiple models to produce predictions, while model interpretability focuses on understanding how a model makes its decisions.

The topics include bagging, random forests, boosting, stacking, AdaBoost, Gradient Boosting, and different approaches to model interpretation.

## Topics Covered

1. Ensemble Methods
2. Bagging
3. Random Forest
4. Boosting and Stacking
5. AdaBoost and Gradient Boosting
6. Model Interpretability
7. Self-Interpretable and Non-Self-Interpretable Models
8. Model-Agnostic Explanations and Surrogate Models

## Learning Objectives

After completing this module, I expect to be able to:

- Explain the concept of ensemble learning.
- Understand how bagging combines multiple models.
- Describe how Random Forest works.
- Understand the differences between bagging, boosting, and stacking.
- Explain AdaBoost and Gradient Boosting.
- Understand the importance of model interpretability.
- Distinguish between self-interpretable and non-self-interpretable models.
- Explain model-agnostic explanations and surrogate models.
