# Module 1 – Logistic Regression and Classification Metrics

## Overview

This module introduces classification as a supervised machine learning task. It focuses on Logistic Regression and the evaluation metrics used to measure classification model performance.

The module also covers practical implementation using Python and Scikit-learn.

## Topics Covered

1. Introduction to Classification
2. Introduction to Logistic Regression
3. Classification with Logistic Regression
4. Logistic Regression with Multiple Classes
5. Implementing Logistic Regression Models
6. Confusion Matrix and Classification Metrics
7. ROC and Precision-Recall Curves

## Learning Objectives

After completing this module, learners should be able to:

- Understand the basic concept of classification.
- Explain how Logistic Regression works.
- Understand binary and multiclass classification.
- Implement Logistic Regression using Scikit-learn.
- Read and interpret a confusion matrix.
- Evaluate classification models using appropriate metrics.
- Understand ROC and Precision-Recall curves.

## Tools and Libraries

- Python

- Pandas
- NumPy
- Matplotlib
- Scikit-learn
