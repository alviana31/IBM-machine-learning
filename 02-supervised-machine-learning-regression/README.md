# Course 2 - Supervised Machine Learning: Regression

## Overview

This course introduces supervised Machine Learning techniques with a focus on regression problems.

It covers the fundamentals of supervised learning, linear regression, model evaluation, data splitting, cross-validation, and regularization techniques.

The course also includes a final project where learners apply regression methods to a dataset and communicate their findings.

## Course Modules

| Module | Topics |
|---|---|
| Module 1 | Introduction to Supervised Machine Learning and Linear Regression |
| Module 2 | Training and Test Splits and Polynomial Regression |
| Module 3 | Cross Validation |
| Module 4 | Bias-Variance Trade-off and Regularization Techniques |
| Module 5 | Details of Regularization |
| Module 6 | Regression Course Project |

## Learning Objectives

After completing this course, learners are expected to:

- Understand the fundamentals of supervised Machine Learning.
- Differentiate regression and classification problems.
- Build and interpret linear regression models.
- Split datasets into training and testing sets.
- Apply polynomial regression.
- Understand and perform cross-validation.
- Evaluate model performance.
- Understand the bias-variance trade-off.
- Apply Ridge, LASSO, and Elastic Net regression.
- Compare regression models and communicate analytical findings.
