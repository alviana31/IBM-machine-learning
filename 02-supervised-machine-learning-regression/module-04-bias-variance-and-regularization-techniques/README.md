# Module 4: Bias-Variance Trade-off and Regularization Techniques

## Overview

This module explores the bias-variance trade-off and regularization techniques used to control model complexity and reduce overfitting.

It introduces three regularization methods: Ridge Regression, LASSO Regression, and Elastic Net. These methods add penalties to the model's cost function to control the size of regression coefficients.

The module also demonstrates how polynomial features can be combined with regularization to build models that capture complex patterns while controlling overfitting.

## Learning Objectives

After completing this module, I am able to:

- Explain bias, variance, and irreducible error.
- Understand the relationship between model complexity and prediction error.
- Describe the purpose of regularization.
- Understand how regularization helps reduce overfitting.
- Differentiate between Ridge, LASSO, and Elastic Net.
- Understand the role of regularization strength.
- Apply regularization to polynomial regression models.
