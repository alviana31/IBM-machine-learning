# Module 2: Training and Test Splits and Polynomial Regression

## Overview

This module explains how to divide a dataset into training and testing sets and how polynomial regression can be used to model nonlinear relationships between features and a target variable.

Training data is used to fit the model, while testing data is used to measure its performance on observations that were not used during training.

The module also introduces polynomial features as a way to capture nonlinear effects while extending a linear regression model.

## Learning Objectives

After completing this module, I am able to:

- Explain the purpose of training and test datasets.
- Understand why data splitting is important for model generalization.
- Perform a training and test split using Scikit-learn.
- Understand the relationship between model complexity and training error.
- Explain the concept of polynomial regression.
- Apply polynomial features to a regression model.
