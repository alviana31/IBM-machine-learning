# Module 3: Cross Validation

## Overview

This module introduces cross-validation as a technique for evaluating machine learning models using multiple training and validation splits.

Instead of relying on a single train-test split, cross-validation repeats the evaluation process across different subsets of the dataset. The resulting performance scores can then be compared or averaged to obtain a more reliable estimate of model performance.

## Learning Objectives

After completing this module, I am able to:

- Explain the purpose of cross-validation.
- Understand the difference between training, validation, and test data.
- Describe the K-Fold Cross-Validation process.
- Understand how multiple data splits are used to evaluate a model.
- Implement cross-validation using Scikit-learn.
- Interpret cross-validation scores.
