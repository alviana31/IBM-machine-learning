# Deep Learning and Neural Network Basics

## 1. Deep Learning Overview

Deep Learning is a part of Machine Learning that uses neural networks to learn patterns and relationships from data.

Deep Learning is widely used in various Artificial Intelligence applications, such as:

- Self-driving cars
- Computer vision
- Speech recognition
- Image classification
- Unsupervised learning

The course introduces neural networks and advanced models such as CNNs, GANs, and Reinforcement Learning.

## 2. Neural Network Basics

Neural Networks are computational models inspired by the way the human brain processes information.

A neural network processes data through several layers. Each layer performs calculations using weights and activation functions to produce an output.

The basic components include:

- **Input:** Data received by the network.
- **Weights:** Values used to determine the influence of each input.
- **Activation Function:** Function that transforms the calculated values.
- **Output:** Result produced by the network.

Neural networks are related to Logistic Regression because both use weighted inputs and activation functions. However, neural networks with multiple layers can learn more complex and non-linear patterns.

## 3. Neural Network Layers

A neural network generally consists of:

1. **Input Layer:** Receives the input data.
2. **Hidden Layer:** Processes information using weights and activation functions.
3. **Output Layer:** Produces the final prediction.

The output of one layer becomes the input for the next layer.

## 4. Weights and Activations

Weights determine how strongly each input contributes to the next layer.

During computation, input values are combined with weights to produce Z-values. These values are then passed through an activation function to generate A-values.

The process continues until the network produces its final output.

## 5. Deep Learning Models

Some common Deep Learning models include:

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Autoencoders
- Generative Adversarial Networks (GAN)
