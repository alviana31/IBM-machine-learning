# Module 01 – Introduction to Neural Networks

## Overview

This module introduces the fundamentals of Deep Learning and Neural Networks. It explains how neural networks process data through layers, use weights and activation functions, and learn patterns from data.

## Topics Covered

1. Deep Learning Overview
2. Neural Network Basics
3. Sigmoid Activation Function
4. Perceptron
5. Multi-Layer Perceptron (MLP)
6. Feed-Forward Computation
7. Data Transformation in MLP

## Learning Objectives

- Understand the basic concepts of Deep Learning.
- Explain how neural networks process input data.
- Understand the role of weights and activation functions.
- Understand the sigmoid activation function.
- Explain the structure of a perceptron and MLP.
- Understand the feed-forward process in neural networks.
