# Module 06 – Recurrent Neural Networks and LSTM

## Overview

This module introduces Recurrent Neural Networks (RNNs) and Long Short-Term Memory Networks (LSTMs). These models are designed to process sequential data by maintaining information from previous inputs.

## Topics Covered

1. Introduction to RNN
2. Hidden States and Predictions
3. Mathematical Details of RNN
4. Backpropagation Through Time (BPTT)
5. RNN Applications
6. Long Short-Term Memory (LSTM)
7. LSTM Gates
8. Gated Recurrent Units (GRU)
9. Sequence-to-Sequence Models
10. Beam Search

## Learning Objectives

- Understand how RNNs process sequential data.
- Explain the role of hidden states.
- Understand Backpropagation Through Time.
- Identify the limitations of standard RNNs.
- Understand LSTM architecture and its gates.
- Compare LSTM and GRU.
- Understand sequence-to-sequence models and beam search.
