# Module 04 – Convolutional Neural Networks

## Overview

This module introduces Convolutional Neural Networks (CNNs), a type of neural network commonly used for image recognition and pattern detection.

It covers image preprocessing, convolution operations, kernels, filters, and techniques for extracting important features from images.

## Topics Covered

1. Preprocessing and Data Preparation
2. Multiclass Classification
3. Softmax Activation Function
4. Categorical Cross-Entropy
5. Introduction to CNN
6. Kernels and Filters
7. Color Images and Channels
8. Grid Size, Padding, and Stride
9. Pooling

## Learning Objectives

- Understand image preprocessing for neural networks.
- Understand how CNNs recognize image patterns.
- Explain the role of kernels and filters.
- Understand RGB color channels.
- Explain padding and stride in convolution.
- Understand pooling for reducing image dimensions.
