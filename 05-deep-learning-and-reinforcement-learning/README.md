# Course 5 – Deep Learning

## Overview

This course covers the fundamentals and applications of Deep Learning, including neural networks, model training, optimization, computer vision, sequence modeling, generative models, and reinforcement learning.

## Learning Modules

| Module | Topic |
|---|---|
| 01 | Introduction to Neural Networks |
| 02 | Back Propagation Training and Keras |
| 03 | Neural Network Optimizers |
| 04 | Convolutional Neural Networks |
| 05 | Transfer Learning |
| 06 | Recurrent Neural Networks and Long Short-Term Memory Networks |
| 07 | Autoencoders |
| 08 | Generative Models and Applications of Deep Learning |
| 09 | Reinforcement Learning |

## Learning Objectives

- Understand the fundamentals of neural networks.
- Learn how neural networks are trained using backpropagation and Keras.
- Understand different neural network optimization methods.
- Explore CNN architectures for image processing.
- Apply transfer learning using pretrained models.
- Understand RNN and LSTM for sequential data.
- Learn the concepts and applications of autoencoders.
- Explore generative models and their applications.
- Understand the fundamentals of reinforcement learning.

## Repository Structure

Each module contains learning notes, important concepts, code examples, and practical exercises when available.
