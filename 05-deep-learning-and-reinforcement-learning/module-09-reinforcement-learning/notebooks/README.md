# Module 9 – Reinforcement Learning Notebooks

This directory contains practical notebooks related to reinforcement learning.

## Suggested Notebook

- `reinforcement-learning-introduction.ipynb` – Explore the interaction between an agent and an environment using a reinforcement learning environment.

## Suggested Experiments

1. Explore a reinforcement learning environment using Python.
2. Identify the agent, state, action, and reward.
3. Observe how the environment responds to different actions.
4. Examine how rewards influence the agent's decisions.
5. Explore a basic reinforcement learning workflow using OpenAI Gym.
