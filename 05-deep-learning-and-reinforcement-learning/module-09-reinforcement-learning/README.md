# Module 9 – Reinforcement Learning

## Overview

This module introduces Reinforcement Learning (RL), a machine learning approach in which an agent interacts with an environment, takes actions, and receives rewards.

The agent learns a policy to choose actions that maximize expected rewards over time.

The module also introduces Deep Reinforcement Learning and its applications.

## Learning Objectives

- Understand the basic concept of Reinforcement Learning.
- Identify the agent, environment, action, reward, and policy.
- Explain how an agent learns through interaction.
- Understand the objective of maximizing expected rewards.
- Identify examples and applications of Deep Reinforcement Learning.

## Topics

1. Introduction to Reinforcement Learning
2. Agent and Environment
3. Actions and Rewards
4. Policy and Expected Rewards
5. Deep Reinforcement Learning
6. Applications of Reinforcement Learning
