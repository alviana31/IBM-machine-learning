# Module 05 – Transfer Learning

## Overview

This module introduces Transfer Learning, a technique that uses pretrained neural networks as a starting point for solving new tasks.

It covers pretrained models, fine-tuning, modern CNN architectures, and regularization techniques.

## Topics Covered

1. Introduction to Transfer Learning
2. Pretrained Models
3. Transfer Learning Workflow
4. Fine-Tuning
5. Inception V3
6. ResNet-50
7. Regularization Techniques

## Learning Objectives

- Understand the concept of Transfer Learning.
- Explain the benefits of using pretrained models.
- Understand how to freeze layers in a base model.
- Apply fine-tuning to improve model performance.
- Identify the characteristics of Inception V3 and ResNet-50.
- Understand regularization techniques used in deep learning.
