# Module 8 – Generative Models and Applications of Deep Learning

## Overview

This module introduces generative models in deep learning, focusing on Variational Autoencoders (VAEs) and Generative Adversarial Networks (GANs).

These models learn patterns and representations from data to generate new samples.

## Learning Objectives

- Understand the concept of generative models.
- Explain how Variational Autoencoders work.
- Understand latent variables and probability distributions in VAEs.
- Explain the main components of Generative Adversarial Networks.
- Understand how generators and discriminators work together.

## Topics

1. Variational Autoencoders (VAE)
2. Latent Variables and Probability Distributions
3. VAE Loss Function
4. Generative Adversarial Networks (GAN)
5. Generator and Discriminator
