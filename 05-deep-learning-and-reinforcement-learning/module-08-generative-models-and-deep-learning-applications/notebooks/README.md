# Module 8 – Generative Models Notebooks

This directory contains practical notebooks related to generative models.

## Suggested Notebooks

- `variational-autoencoder.ipynb` – Implementation of a basic VAE for learning latent representations and generating samples.
- `generative-adversarial-network.ipynb` – Implementation of a basic GAN using a generator and discriminator.

## Suggested Experiments

1. Explore how a VAE encoder produces mean and standard deviation.
2. Observe how latent sampling affects generated outputs.
3. Examine reconstruction and regularization losses.
4. Build a generator and discriminator.
5. Observe the changes in generated samples during GAN training.

## Notes

The course material introduces VAE and GAN concepts. These notebooks are suggested practical exercises, not provided implementations from the course material.
