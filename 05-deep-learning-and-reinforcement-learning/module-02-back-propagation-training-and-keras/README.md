# Module 02 – Back Propagation Training and Keras

## Overview

This module covers the process of training neural networks using backpropagation and gradient-based optimization. It also introduces Keras as a high-level library for building and training neural network models.

## Topics Covered

1. Neural Network Training Process
2. Feed-Forward Computation
3. Loss Function
4. Backpropagation
5. Weight Updates
6. Gradient Descent
7. Stochastic Gradient Descent
8. Mini-Batch Gradient Descent
9. Building Models with Keras

## Learning Objectives

- Understand the steps involved in training a neural network.
- Explain the role of loss functions and gradients.
- Understand how backpropagation updates network weights.
- Understand gradient descent and its variations.
- Build and train neural network models using Keras.
