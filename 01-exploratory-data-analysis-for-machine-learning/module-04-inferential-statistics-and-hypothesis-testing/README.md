# Module 4 - Inferential Statistics and Hypothesis Testing

## Overview

This module introduces Inferential Statistics and Hypothesis Testing. It focuses on using sample data to understand population characteristics, estimate parameters, and evaluate statistical hypotheses.

## Learning Objectives

After completing this module, learners are expected to:

- Understand estimation and statistical inference.
- Differentiate between parametric and non-parametric approaches.
- Recognize commonly used probability distributions.
- Understand frequentist and Bayesian statistics.
- Explain null and alternative hypotheses.
- Understand Type I and Type II errors.
- Interpret significance levels and p-values.
- Understand the difference between correlation and causation.

## Topics Covered

1. Estimation and Inferential Statistics.
2. Parametric and Non-Parametric Approaches.
3. Commonly Used Distributions.
4. Frequentist and Bayesian Statistics.
5. Hypothesis Testing.
6. Significance Levels and P-Values.
7. Correlation vs. Causation.

## Module Structure

- `notes/`: Learning notes and explanations.
- `notebooks/`: Practical exercises and Python implementations.

## Key Learning Outcome

Understand fundamental statistical inference concepts and apply hypothesis testing principles to interpret data and evaluate relationships between variables.
