
# Module 4 - Inferential Statistics and Hypothesis Testing

## Overview
This module introduces inferential statistics and hypothesis testing. It explains how sample data can be used to understand population characteristics, estimate parameters, and evaluate statistical hypotheses.

## Learning Objectives
- Understand estimation and statistical inference.
- Differentiate between parametric and non-parametric approaches.
- Recognize commonly used probability distributions.
- Understand Frequentist and Bayesian statistics.
- Formulate and evaluate statistical hypotheses.
- Interpret significance levels and p-values.
- Understand the difference between correlation and causation.

## Topics Covered

### 1. Estimation and Inference
Inferential statistics uses information from a sample to understand characteristics of a larger population.

Important concepts:
- Population: The entire group being studied.
- Sample: A subset of the population.
- Parameter: A numerical characteristic of a population.
- Statistic: A numerical characteristic calculated from a sample.
- Estimation: The process of estimating population parameters using data.

### 2. Parametric and Non-Parametric Methods
Parametric methods use assumptions about the underlying data distribution and involve parameters such as the mean and standard deviation.

Non-parametric methods do not rely on the same specific distribution assumptions.

### 3. Commonly Used Distributions
The course introduces several probability distributions:
- Uniform Distribution
- Normal Distribution
- Log-Normal Distribution
- Exponential Distribution
- Poisson Distribution

### 4. Frequentist vs. Bayesian Statistics
Frequentist statistics focuses on the behavior of repeated observations or experiments.

Bayesian statistics represents uncertainty about parameters using probability distributions and incorporates prior information.

### 5. Hypothesis Testing
Hypothesis testing is a statistical method used to evaluate statements about population parameters.

Two common hypotheses are:
- Null Hypothesis (H0): The initial hypothesis being evaluated.
- Alternative Hypothesis (H1): The competing hypothesis.

### 6. Type I and Type II Errors
- Type I Error: Rejecting a true null hypothesis.
- Type II Error: Failing to reject a false null hypothesis.

### 7. Significance Level and P-Values
The significance level is a probability threshold selected before conducting a hypothesis test. Common values include 0.01 and 0.05.

A p-value represents the smallest significance level at which the null hypothesis would be rejected.

### 8. Correlation vs. Causation
Correlation describes an association between variables, but it does not necessarily mean that one variable causes changes in another.

Confounding variables and spurious correlations should be considered when interpreting relationships in data.

## Key Takeaways
Inferential statistics helps draw conclusions about populations using sample data. Hypothesis testing provides a structured approach to evaluating claims, while understanding correlation and causation helps prevent incorrect interpretations.
