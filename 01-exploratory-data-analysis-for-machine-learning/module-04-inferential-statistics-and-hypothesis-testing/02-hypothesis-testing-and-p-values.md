# Hypothesis Testing and P-Values

## 1. Introduction

Hypothesis Testing is a statistical method used to evaluate a statement about a population parameter.

It helps determine whether the available sample data provides sufficient evidence to reject a particular hypothesis.

## 2. Types of Hypotheses

A hypothesis test commonly involves two hypotheses:

### 2.1 Null Hypothesis (H0)

The null hypothesis represents the initial statement being tested.

It commonly assumes that there is no significant effect or difference.

### 2.2 Alternative Hypothesis (H1)

The alternative hypothesis represents the statement considered when the null hypothesis is rejected.

It commonly indicates that an effect or difference exists.

## 3. Hypothesis Testing Process

A general hypothesis testing process includes:

1. Define the null hypothesis and alternative hypothesis.
2. Choose a significance level.
3. Calculate the test statistic.
4. Determine the p-value.
5. Compare the p-value with the significance level.
6. Make a statistical conclusion.

A hypothesis test provides a decision rule for determining when the null hypothesis should be rejected.

## 4. Type I and Type II Errors

Hypothesis testing can produce two types of errors.

### 4.1 Type I Error

A Type I error occurs when the null hypothesis is rejected even though the observed effect is actually due to chance.

It is also known as a false positive.

### 4.2 Type II Error

A Type II error occurs when an actual effect is incorrectly treated as being due to chance.

It is also known as a false negative.

## 5. Significance Level

The significance level is a probability threshold used to determine when the null hypothesis can be rejected.

It must be selected before calculating the test statistic.

Common significance levels include:

- 0.01 (1%).
- 0.05 (5%).

## 6. P-Value

A p-value is the smallest significance level at which the null hypothesis would be rejected.

The p-value is compared with the selected significance level.

A common decision rule is:

- If p-value is less than or equal to the significance level, reject the null hypothesis.
- If p-value is greater than the significance level, do not reject the null hypothesis.

## 7. F Statistic

The course also introduces the F statistic as part of the discussion about significance levels and p-values.

The F statistic is a test statistic used in certain statistical tests.

## 8. Confidence Interval

A confidence interval represents a range of values associated with an estimate.

The course discusses confidence intervals in relation to values of a statistic for which the null hypothesis is not rejected.

## Key Takeaways

- Hypothesis testing evaluates statements about population parameters.
- The null hypothesis and alternative hypothesis are the two main hypotheses.
- Type I and Type II errors represent different incorrect decisions.
- Significance levels are selected before calculating the test statistic.
- Common significance levels are 0.01 and 0.05.
- A p-value is compared with the significance level to make a statistical decision.
- The F statistic is also introduced in this module.
