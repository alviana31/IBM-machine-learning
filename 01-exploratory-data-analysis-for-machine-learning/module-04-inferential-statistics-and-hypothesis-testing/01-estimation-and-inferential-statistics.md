# Estimation and Inferential Statistics

## 1. Introduction

Inferential Statistics is the process of learning characteristics of a population from a sample.

It allows researchers and data analysts to use sample information to make conclusions about a larger population.

## 2. Population and Sample

Two important concepts in inferential statistics are:

- **Population:** The complete group of individuals or observations being studied.
- **Sample:** A smaller group selected from the population for analysis.

Population characteristics are called parameters, while sample characteristics are called statistics.

## 3. Parameters and Statistics

A parameter describes a characteristic of a population.

A statistic describes a characteristic calculated from a sample.

For example:

- Population mean is a parameter.
- Sample mean is a statistic.
- Population standard deviation is a parameter.
- Sample standard deviation is a statistic.

## 4. Estimation

Estimation is the process of determining a population parameter based on a model fitted to sample data.

A parametric model uses a certain number of parameters, such as the mean and standard deviation.

One common method for estimating parameters in a parametric model is Maximum Likelihood Estimation (MLE).

## 5. Parametric and Non-Parametric Approaches

### 5.1 Parametric Approach

A parametric model uses a specified set of parameters to describe a statistical model.

Examples of parameters include:

- Mean.
- Standard deviation.

### 5.2 Non-Parametric Approach

Non-parametric methods do not rely on the same fixed parameter structure as parametric models.

The course introduces the comparison between these two approaches as part of statistical inference.

## 6. Commonly Used Probability Distributions

The course introduces several commonly used distributions:

- **Uniform Distribution:** Represents outcomes with equal probabilities across a specified range.
- **Normal Distribution:** A symmetric, bell-shaped distribution.
- **Log-Normal Distribution:** A distribution in which the logarithm of the variable follows a normal distribution.
- **Exponential Distribution:** Commonly used to represent waiting times.
- **Poisson Distribution:** Used to describe the number of events occurring within a fixed interval.

## 7. Frequentist and Bayesian Statistics

### 7.1 Frequentist Statistics

Frequentist statistics focuses on repeated observations or experiments.

It estimates probabilities using observed data and repeated outcomes.

### 7.2 Bayesian Statistics

Bayesian statistics describes parameters through probability distributions.

It incorporates prior information and updates beliefs using observed data.

## Key Takeaways

- Inferential Statistics uses sample data to understand population characteristics.
- Population characteristics are called parameters.
- Sample characteristics are called statistics.
- Estimation determines population parameters based on sample data.
- Maximum Likelihood Estimation is a common parameter estimation method.
- Common distributions include uniform, normal, log-normal, exponential, and Poisson.
- Frequentist and Bayesian statistics use different approaches to statistical inference.
