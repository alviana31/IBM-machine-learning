
# Module 2 - Retrieving Data and Cleaning Data

## Overview
This module focuses on retrieving data from different sources and preparing it for Machine Learning applications. It introduces common data formats, data access methods, and data cleaning techniques to improve data quality before analysis and modeling.

## Learning Objectives
- Understand how to retrieve data from different sources.
- Read and process CSV and JSON files using Python.
- Understand data retrieval from databases, APIs, and cloud platforms.
- Identify common data quality problems.
- Understand how to handle missing values and outliers.

## Topics Covered

### 1. Retrieving Data from CSV and JSON Files
CSV (Comma-Separated Values) is a common format for storing tabular data. Python Pandas provides `read_csv()` to load CSV files into DataFrames.

JSON (JavaScript Object Notation) stores structured data using key-value pairs. Pandas provides `read_json()` to read JSON files and `to_json()` to export data.

### 2. Retrieving Data from Databases, APIs, and the Cloud
Machine Learning projects may require data from different sources, including:
- SQL databases
- NoSQL databases
- Application Programming Interfaces (APIs)
- Cloud data sources

Understanding these sources helps ensure that relevant data can be accessed for further processing.

### 3. Data Cleaning
Data cleaning is the process of identifying and addressing problems in datasets. Poor-quality data can affect the learning process and the performance of Machine Learning models.

Common data issues include:
- Missing values
- Duplicate records
- Inconsistent text values
- Unnecessary data
- Outliers

### 4. Handling Missing Values and Outliers
Missing values and outliers need to be examined before model development. The appropriate treatment depends on the characteristics of the dataset.

The course also introduces the use of residuals when examining missing values and outliers.

## Key Takeaways
Data retrieval and cleaning are essential steps in a Machine Learning workflow. Reliable data provides a better foundation for exploratory analysis and model development.
