# Introduction to Artificial Intelligence, Machine Learning, and Deep Learning

## 1. Artificial Intelligence (AI)

Artificial Intelligence (AI) is a branch of computer science
that focuses on creating systems capable of simulating
intelligent human behavior.

AI allows computers to perform tasks that generally require
human intelligence, such as learning, problem-solving,
recognizing patterns, and making decisions.

## 2. Machine Learning (ML)

Machine Learning is a field of AI that focuses on developing
algorithms that can learn patterns from data without being
explicitly programmed for every task.

Instead of manually defining every rule, an ML model learns
from examples and uses the patterns it discovers to make
predictions or decisions.

## 3. Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses
multi-layered neural networks to learn complex patterns
from large amounts of data.

Deep Learning is commonly used for tasks involving images,
audio, and other complex data.

## 4. Differences Between AI, ML, and DL

- Artificial Intelligence: The broader concept of machines
  performing tasks that require intelligence.
- Machine Learning: A subset of AI that learns patterns
  from data.
- Deep Learning: A subset of ML that uses multi-layered
  neural networks.

## 5. Relationship Between AI, ML, and DL

Deep Learning is part of Machine Learning, while Machine
Learning is part of Artificial Intelligence.

In other words:

AI → Machine Learning → Deep Learning

## Key Takeaways

- AI focuses on simulating intelligent behavior.
- ML allows systems to learn patterns from data.
- DL uses multi-layered neural networks.
- These technologies are related but have different scopes.
