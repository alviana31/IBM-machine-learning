# Module 2 – Computational Hurdles of Clustering Algorithms

## Overview

This module discusses computational challenges in clustering algorithms, particularly the use of distance metrics and the Curse of Dimensionality.

Distance metrics are used to measure how similar or different data points are. Choosing an appropriate metric is important because it can affect how clustering algorithms group the data.

The module also explores how increasing the number of dimensions can affect distance calculations and model performance.

## Learning Objectives

After completing this module, I should be able to:

- Understand the role of distance metrics in clustering.
- Explain Euclidean and Manhattan distance.
- Understand Cosine and Jaccard distance.
- Recognize the differences between distance metrics.
- Explain the Curse of Dimensionality.
- Understand how high-dimensional data can affect clustering performance.
