# Module 4 – Dimensionality Reduction

## Overview

This module introduces dimensionality reduction as a technique for simplifying datasets while preserving important information.

It focuses on Principal Component Analysis (PCA) and Singular Value Decomposition (SVD). The module also explores how dimensionality reduction can be applied to image data.

## Learning Objectives

After completing this module, I should be able to:

- Explain the concept of dimensionality reduction.
- Understand why reducing the number of features can be useful.
- Explain how Principal Component Analysis works.
- Understand principal components and explained variance.
- Understand the basic concept of Singular Value Decomposition.
- Recognize how dimensionality reduction can be applied to image compression.

## Topics Covered

1. Dimensionality Reduction Overview
2. Principal Component Analysis (PCA)
3. Matrix Review
4. Applying PCA
5. Singular Value Decomposition (SVD)
6. Dimensionality Reduction Imaging Example
