# Module 5 – Kernel PCA and Multidimensional Scaling

## Overview

This module explores nonlinear dimensionality reduction techniques, focusing on Kernel Principal Component Analysis (Kernel PCA) and Multidimensional Scaling (MDS).

Kernel PCA extends traditional PCA by using kernel methods to capture nonlinear structures in data. MDS focuses on preserving distances between data points when representing them in a lower-dimensional space.

## Learning Objectives

After completing this module, I should be able to:

- Explain the concept of Kernel PCA.
- Understand the difference between linear PCA and Kernel PCA.
- Identify different kernel functions.
- Understand the role of gamma and alpha parameters.
- Explain the concept of Multidimensional Scaling.
- Differentiate between Metric MDS and Non-Metric MDS.
- Implement Kernel PCA and MDS using Scikit-learn.
