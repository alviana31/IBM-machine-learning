# Introduction to Unsupervised Learning

## 1. Definition

Unsupervised Learning is a type of machine learning that works with data without predefined labels or target values.

Unlike supervised learning, the model does not receive the correct output during training. Instead, it tries to identify patterns, relationships, or structures within the dataset.

The main purpose is to discover information that may not be immediately visible in the data.

## 2. Supervised vs. Unsupervised Learning

| Aspect | Supervised Learning | Unsupervised Learning |
|---|---|---|
| Training data | Labeled data | Unlabeled data |
| Target variable | Available | Not available |
| Main purpose | Predict an output | Discover patterns |
| Common tasks | Classification and Regression | Clustering and Dimensionality Reduction |

## 3. Clustering

Clustering is an unsupervised learning technique used to group data points based on their similarities.

Data points within the same cluster should have similar characteristics, while data points from different clusters should have different characteristics.

For example, a website can group its customers based on their activity, such as the number of visits and how recently they visited.

## 4. Use Cases of Clustering

Some common applications include:

- **Customer segmentation:** Grouping customers based on behavior or purchasing patterns.
- **Marketing:** Identifying customer groups for targeted campaigns.
- **Image analysis:** Grouping similar images or visual patterns.
- **Data exploration:** Finding hidden structures in a dataset.
- **Business analysis:** Identifying groups with similar characteristics.

## 5. Introduction to Clustering Process

The general clustering process involves:

1. Preparing the dataset.
2. Selecting relevant features.
3. Choosing a clustering algorithm.
4. Defining or estimating the number of clusters, depending on the algorithm.
5. Running the algorithm.
6. Analyzing and interpreting the resulting clusters.

The output is a set of groups based on the patterns identified in the data.

## 6. Important Concepts

- **Data point:** An individual observation in a dataset.
- **Feature:** A variable or characteristic used to describe a data point.
- **Cluster:** A group of data points with similar characteristics.
- **Centroid:** The center point representing a cluster in K-Means.

## 7. Key Takeaways

- Unsupervised learning uses data without predefined labels.
- Clustering is one of the main techniques in unsupervised learning.
- Clustering helps discover patterns and group similar observations.
- The results need to be interpreted based on the context of the data and the problem.
