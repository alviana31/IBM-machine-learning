# Module 3 – Common Clustering Algorithms

## Overview

This module explores several clustering algorithms used in unsupervised machine learning. It focuses on Hierarchical Agglomerative Clustering, DBSCAN, and Mean Shift.

Each algorithm has a different approach to identifying groups in a dataset. Understanding their characteristics helps determine which method is appropriate for a particular problem.

## Learning Objectives

After completing this module, I should be able to:

- Explain Hierarchical Agglomerative Clustering.
- Understand different hierarchical linkage methods.
- Explain how DBSCAN identifies clusters.
- Understand core points, border points, and noise points in DBSCAN.
- Explain the Mean Shift algorithm.
- Compare different clustering algorithms based on their characteristics and applications.
