# Module 6 – Matrix Factorization

## Overview

This module introduces Matrix Factorization, with a focus on Non-Negative Matrix Factorization (NMF). The technique decomposes a non-negative data matrix into two smaller non-negative matrices.

NMF can be applied to text data, such as document-term matrices, to identify topics and understand how words contribute to different topics.

## Learning Objectives

After completing this module, I should be able to:

- Understand the basic concept of matrix factorization.
- Explain how Non-Negative Matrix Factorization works.
- Understand the role of matrices W and H in NMF.
- Apply NMF to non-negative data.
- Understand how NMF can be used for topic modeling.
- Recognize the role of TF-IDF in text data representation.

## Topics Covered

1. Introduction to Matrix Factorization
2. Non-Negative Matrix Factorization (NMF)
3. NMF for Topic Modeling
4. TF-IDF as a Text Feature Weighting Method
