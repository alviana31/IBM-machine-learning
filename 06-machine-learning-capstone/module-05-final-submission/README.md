# Module 5 – Final Submission

## Overview

This module covers the final stage of the Machine Learning Capstone Project and introduces Streamlit as a tool for developing interactive web applications.

Streamlit is an open-source Python library designed for applications involving machine learning, data analysis, and data visualization.

It allows developers and data scientists to build interactive web applications directly from Python scripts without requiring extensive knowledge of HTML, CSS, or JavaScript.

## Learning Objectives

- Understand the purpose of Streamlit.
- Identify the applications of Streamlit in machine learning and data analysis.
- Understand how Streamlit supports interactive web applications.
- Recognize the local environment requirements for running Streamlit applications.
- Prepare the final capstone project submission.

## Topics

1. Introduction to Streamlit
2. Streamlit for Machine Learning Applications
3. Local Environment
4. Streamlit Application Deployment
