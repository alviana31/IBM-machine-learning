The final submission is the last stage of the Machine Learning Capstone Project.

The capstone project provides an opportunity to apply machine learning knowledge and techniques to a real-world recommender system problem.

## 2. Project Scope

The capstone project brings together concepts from previous machine learning courses, including:

- Regression
- Classification
- Clustering
- Deep Learning
- Recommender Systems

These techniques support the development of a recommendation solution using user-item interaction data.
