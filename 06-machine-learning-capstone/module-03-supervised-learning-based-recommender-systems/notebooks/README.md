# Module 3 – Collaborative Filtering Notebooks

This directory contains practical notebooks related to collaborative filtering.

## Suggested Notebook

- `collaborative-filtering.ipynb` – Build a simple recommendation system using a user-item rating matrix.

## Suggested Experiments

1. Create a sample user-item rating matrix.
2. Calculate similarity between users.
3. Calculate similarity between items.
4. Apply Euclidean Distance, Pearson Correlation, or Cosine Similarity.
5. Build a weighted rating matrix.
6. Calculate predicted ratings for unrated items.
7. Compare user-based and item-based recommendations.
8. Explore the effects of data sparsity.

## Notes

The notebook is a suggested practical implementation based on the concepts in the course material. The PDF does not provide a complete executable implementation.
