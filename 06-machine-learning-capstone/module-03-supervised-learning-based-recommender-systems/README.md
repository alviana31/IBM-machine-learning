# Module 3 – Supervised-Learning Based Recommender Systems

## Overview

This module introduces Collaborative Filtering, a recommender system technique that uses relationships between users and items to generate recommendations.

Collaborative filtering identifies users with similar preferences or items that receive similar ratings from users.

## Learning Objectives

- Understand the concept of collaborative filtering.
- Identify user-based and item-based approaches.
- Understand user similarity and item similarity.
- Explore similarity measurement techniques.
- Calculate weighted ratings.
- Understand the challenges of collaborative filtering.

## Topics

1. Introduction to Collaborative Filtering
2. User-Based Collaborative Filtering
3. Item-Based Collaborative Filtering
4. Similarity Measurements
5. Weighted Rating Matrix
6. Data Sparsity
7. Cold Start Problem
8. Scalability
