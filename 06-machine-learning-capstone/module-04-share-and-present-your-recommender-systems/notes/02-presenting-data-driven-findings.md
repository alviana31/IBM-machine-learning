# Presenting Data-Driven Findings

## 1. Introduction

A data-driven presentation communicates the results of an analysis to an audience.

The goal is to ensure that the audience understands the main findings and the message behind the data.

A presentation should be designed according to the audience and should focus on the most important information.

## 2. Best Practices for Presenting Findings

The course material highlights several important practices.

### 2.1 Make Charts and Graphs Easy to Read

Charts and graphs should:

- Be large enough to read.
- Have clear labels.
- Be understandable from different viewing distances.

Test the visualizations from different distances to ensure that the audience can see the information clearly.

### 2.2 Use Data as Supporting Evidence

Data should support the main message of the presentation.

Avoid filling slides with excessive numbers and technical details that may make the presentation difficult to understand.

Start by identifying the key messages, then use relevant data to support them.

### 2.3 Share One Main Point per Chart

Each chart or graph should communicate one clear idea.

Combining too many different messages in one visualization can confuse the audience.

Keep each visualization focused on the finding it is intended to explain.

### 2.4 Remove Unnecessary Information

Not every result from an analysis needs to appear in the presentation.

Include information that supports the key findings and remove details that are not relevant to the project.

This helps keep the presentation clear and concise.

## 3. Building a Clear Presentation

A useful approach is:

1. Identify the key messages.
2. Create an outline based on those messages.
3. Select data that supports each message.
4. Choose suitable charts or graphs.
5. Make sure visualizations are readable.
6. Remove information that does not support the main points.
7. Present the findings in a clear and organized way.

## 4. Common Presentation Problems

| Problem | Recommended Practice |
|---|---|
| Charts are too small | Increase chart size and improve readability |
| Labels are difficult to read | Use clear and readable labels |
| Slides contain too much data | Focus on key messages |
| One chart contains too many ideas | Present one main point per chart |
| Irrelevant information is included | Remove data that does not support the findings |

## 5. Key Takeaways

- A presentation should communicate the main findings clearly.
- Charts and graphs must be readable and properly labeled.
- Data should support the message rather than overwhelm the audience.
- Each visualization should focus on one main point.
- Unnecessary information should be removed.
- The presentation should be designed around the audience's needs.
