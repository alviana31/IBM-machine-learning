# IBM Machine Learning Capstone

## Overview

This course brings together the machine learning concepts and techniques covered in the previous courses.

The capstone project focuses on building a recommender system using real-world data. The main objective is to predict whether a user will like a particular item.

The project applies different machine learning approaches, including regression, classification, clustering, and recommender system techniques.

## Learning Objectives

- Apply supervised and unsupervised machine learning techniques.
- Understand the fundamentals of recommender systems.
- Build content-based recommendation systems.
- Understand user-based and item-based collaborative filtering.
- Evaluate and compare recommendation approaches.
- Communicate project findings through reports and presentations.
- Develop and submit a machine learning capstone project.
