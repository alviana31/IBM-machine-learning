# Module 2 – Content-Based Recommender System Notebooks

This directory contains practical notebooks related to content-based recommender systems.

## Suggested Notebook

- `content-based-recommender-system.ipynb` – Build a simple movie recommendation system using user ratings and movie genre features.

## Suggested Experiments

1. Create a sample movie dataset containing movie titles and genres.
2. Create user ratings for previously watched movies.
3. Apply one-hot encoding to movie genres.
4. Build a weighted genre matrix.
5. Create a normalized user profile.
6. Calculate scores for candidate movies.
7. Rank movies based on predicted user interest.

## Notes

The notebook is a suggested practical implementation based on the concepts explained in the course material. The PDF does not provide a complete executable notebook or dataset.
