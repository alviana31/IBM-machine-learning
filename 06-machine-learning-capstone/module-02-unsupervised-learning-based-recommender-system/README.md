# Module 2 – Unsupervised-Learning Based Recommender System

## Overview

This module focuses on Content-Based Recommender Systems.

Content-based filtering recommends items based on a user's profile, preferences, and the characteristics of items.

The recommendation process uses item features and user ratings to build a user profile and calculate the potential interest level in items that the user has not previously interacted with.

## Learning Objectives

- Understand the concept of content-based recommender systems.
- Explain how user preferences are represented.
- Understand one-hot encoding for item features.
- Build a user profile using ratings and item features.
- Calculate weighted genre scores.
- Rank candidate items based on predicted user interest.
- Understand the limitations of content-based filtering.
