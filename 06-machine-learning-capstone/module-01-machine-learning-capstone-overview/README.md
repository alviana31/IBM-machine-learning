# Module 1 – Machine Learning Capstone Overview

## Overview

This module introduces the Machine Learning Capstone Project and provides a review of the machine learning techniques covered in previous courses.

The capstone project focuses on recommender systems, particularly predicting whether a user will like a specific item.

## Learning Objectives

- Review regression and classification algorithms.
- Understand unsupervised learning and dimensionality reduction.
- Understand the role of deep learning in machine learning applications.
- Explain the purpose of recommender systems.
- Identify the main types of recommender systems.
- Understand memory-based and model-based approaches.

## Topics

1. Machine Learning Capstone Introduction
2. Review of Machine Learning Algorithms
3. Introduction to Recommender Systems
4. Benefits of Recommender Systems
5. Types of Recommender Systems
6. Memory-Based and Model-Based Approaches
